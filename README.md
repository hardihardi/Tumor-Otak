# Sistem Analisis dan Deteksi Tumor Otak Berbasis Machine Learning
## Studi Kasus: Bumame

### 1. Latar Belakang Produk
Tumor otak memerlukan diagnosis cepat dan akurat. MRI menjadi metode utama, namun proses interpretasi manual oleh radiolog membutuhkan waktu dan rentan terhadap variasi subjektif.
Sistem analisis berbasis Machine Learning membantu mendeteksi pola tumor pada citra MRI secara otomatis.

### 2. Arsitektur Sistem
- **Frontend**: React.js
- **Backend Service**: Go (Golang)
- **ML Service**: Python (FastAPI)
- **Database**: PostgreSQL
- **Storage**: S3 / MinIO
